# Megh-Suryam 🌦️☀️

A weather app I built when I was 15 years old, in Python + tkinter.

## What it does
- 🌤️ **Current weather** — for any city by name
- ⏩ **Future forecast** — upcoming conditions
- 🕰️ **Historical weather** — by latitude & longitude
- 🎤 **Voice input** — using `speech_recognition`
- 🧵 **Threading** — for non-blocking voice listening

## Stack
- Python 3
- tkinter (GUI)
- requests (API)
- speech_recognition (voice)
- OpenWeatherMap API

## Note
The API key in the source is expired (and was never meant to be secret — it's a free-tier key). This app is a time capsule of my early days in programming.

## Legacy
This was my first *published* app. It ran on Google Play before being taken down for under-18 policy. It's the beginning of everything I've built since. 🕯️
